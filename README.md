# ACNHRecomp-Importer — downloads

Ready-to-run builds of **ACNHRecomp-Importer**, the companion app of [ACNHRecomp](https://github.com/Nycolazs/ACNHRecomp). It turns **your own copy** of *Animal Crossing: New Horizons* (NSP or XCI, its update and your console's keys) into the game folder ACNHRecomp plays.

**Download:** see [Releases](../../releases/latest).

| System | File |
|---|---|
| Windows 10/11 (x64) | `ACNH-Recomp-Importer-windows-x64.exe` — one file, double-click it |
| macOS (Apple Silicon) | `ACNH-Recomp-Importer-macos-arm64.zip` — unzip and open; the first time: System Settings > Privacy & Security > Open Anyway |
| Linux (x64) | `ACNH-Recomp-Importer-linux-x64` — `chmod +x` it and run it (also on Steam Deck / SteamOS; do not use the Windows build under Wine or Proton) |
| Android 10+ | `ACNH-Recomp-Importer-android.apk` |

No part of the game, no keys and no firmware are included in these files. Use them only with a game you own, dumped from your own console.
